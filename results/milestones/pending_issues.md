# 进展报告「待解决问题」对照（截至 v5）

对照来源：`中文文本情感分析进展报告.pdf` 第五节

## 已解决 / 已基本解决

| 报告条目 | 报告中的问题 | 当前状态（v5） |
|----------|--------------|----------------|
| **5.1 中性识别** | 中性文本误判率高 | **已解决**：中性 F1 **0.8348**，召回 **92.2%** |
| **5.2 缓解过拟合** | 训练 acc 升、验证平稳 | **已实施**：Dropout 0.5、L2 `1e-4`、早停（macro-F1） |
| **5.3 多维度评估** | 仅有准确率与 loss | **已补充**：P/R/F1、混淆矩阵、`eval_latest.json` |
| **5.4 类别平衡** | 中性样本过少 | **已实施**：v2 起 1:1:1 均衡 + 多轮样本增强 |
| **5.5 结构升级（部分）** | 需注意力、词典加权 | **已完成**：BiLSTM+注意力、情感词典加权、推理校准 |

## 仍未解决 / 仅部分解决

| 报告条目 | 具体问题 | 说明 |
|----------|----------|------|
| **5.5 CNN-LSTM 混合** | 报告建议的另一种结构 | **未做**；双模型集成试验未超 v5，已放弃 |
| **边界/弱情感句** | 语义平淡、概率接近的句子 | v5 案例「一般般，没有惊喜也没有失望」仍偏边界 |
| **反讽与表情不一致** | 真实微博复杂表达 | 日志估计此类场景约 **75%～80%**，未专项优化 |
| **原始分布泛化评估** | 未下采样真实比例测试集 | **v5 已实测**（见 `eval_v5_generalization_comparison.md`）：accuracy 72.60%，macro-F1 0.5536，**中性召回仅 10.5%** |
| **预训练模型迁移** | MacBERT / ERNIE 等 | 时间成本较高，**未迁移**；BiLSTM 架构已近上限 (~86%) |
| **训练过程曲线归档** | 各轮 epoch 级 acc/loss | 仅最后一轮覆盖保存，**历史曲线未保留**（汇报用各轮测试 acc 代替） |

## 汇报时可用的「不足与展望」表述

1. 在**均衡测试集**上表现良好，**原始类别分布**下的泛化尚未完整评估。  
2. **弱情感、反讽、表情与文字矛盾**的样本仍是难点。  
3. 当前为 **BiLSTM + 词典 + 校准** 路线；**CNN-LSTM 混合、预训练 BERT 微调**可作为后续工作。
